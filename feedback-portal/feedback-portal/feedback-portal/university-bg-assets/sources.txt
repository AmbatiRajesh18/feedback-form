Note on downloading:
--------------------
This sandbox's network egress is restricted to an allowlist that does
not include images.unsplash.com, so the actual image bytes could not
be fetched and saved here automatically. The website currently
hotlinks image #1 directly from Unsplash's CDN (which is permitted
under the license and needs no local file).

To get real local copies in this folder:
  1. Open any "Page" link above in a browser.
  2. Click Download on the photo.
  3. Save the file into this folder (university-bg-assets/).
  4. Send it back to me and I'll wire the local file into the page
     instead of the hotlink.
